Let's GPC

少做事，但把核心信号做对。

Global Privacy Control

为 HTTP(S) 请求添加 Sec-GPC: 1，并在顶层网页暴露只读 JavaScript 属性。

阻止 Chrome Topics

直接关闭浏览器 Topics API，不修改站点的 Permissions-Policy。

域名列表

0 个本地记录；关闭某域名后，它及其子域作为顶层网站时整页不发送 GPC。

域名 最后记录 发送 GPC

尚无域名记录。

边界与隐私

  • 没有遥测、远程配置、广告或第三方运行时依赖。
  • 域名历史仅保存在 Chrome 本地存储；仅在打开弹窗时读取页面已有的资源计时条目。
  • 网站的 /.well-known/gpc.json 只在打开弹窗时按需检查；它是支持声明，不是合规证明。
  • Chrome 扩展无法向 Web Worker 注入 WorkerNavigator.globalPrivacyControl；请求头仍由浏览器网络栈添加。
